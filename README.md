# 🌐 Internet Connection Status Checker

A simple and interactive web application that detects your internet connection status in real-time.  
It displays whether you're online or offline, your public IP address, and your network strength using the latest browser APIs.

🚀 **Live Demo:** https://internet-connection-check.vercel.app  

---

## 📌 Features

✅ **Real-time Internet Status Detection**  
Automatically checks if you are connected or disconnected.

✅ **Public IP Address Fetching**  
Displays your current public IP using `api.ipify.org`.

✅ **Network Strength Check**  
Uses the `navigator.connection` API to detect network downlink speed.

✅ **Visual Status Colors**  
- 🟢 Green → Connected  
- 🔴 Red → Disconnected

✅ **Responsive & Clean UI**  
Built with a modern, card-style layout that works on all devices.
